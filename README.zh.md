# dsh-animal-island-theme

[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的动物岛主题。奶油色与青绿配色、带按压底边的胶囊按钮、内嵌式开关，英文使用 Nunito 圆体，中文优化中西文间距、标点挤压与禁则换行。支持浅色和深色模式。

配色和控件形状参照 [animal-island-ui](https://github.com/guokaigdg/animal-island-ui)（MIT）。内嵌的 Nunito 拉丁子集使用 SIL Open Font License 1.1，见 [assets/fonts/OFL.txt](assets/fonts/OFL.txt)。

## 安装

在 Harness 插件管理器里用这个 Git 地址安装：

```text
git+https://github.com/nagisa-win/dsh-animal-island-theme.git#v0.1.0
```

也可以添加插件索引，在「发现」里安装：

```text
https://nagisa-win.github.io/dsh-animal-island-theme/index.json
```

需要 DSH `>=0.2.2-rc.1`。
