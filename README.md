# dsh-animal-island-theme

Animal Island style theme for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). Cream and teal palette, pill buttons with a pressed lip, inset switches, Nunito for Latin text, and CJK-aware spacing and line breaking. Light and dark mode both included.

Colors and control shapes are adapted from [animal-island-ui](https://github.com/guokaigdg/animal-island-ui) (MIT). The embedded Latin subset of Nunito is licensed under the SIL Open Font License 1.1; see [assets/fonts/OFL.txt](assets/fonts/OFL.txt).

## Install

In the Harness plugin manager, install from this Git repository:

```text
git+https://github.com/nagisa-win/dsh-animal-island-theme.git#v0.1.0
```

Or add the plugin index and install from Discover:

```text
https://nagisa-win.github.io/dsh-animal-island-theme/index.json
```

Requires DSH `>=0.2.2-rc.1`.
